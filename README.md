# Bat-Ball-Stump-Game
upto 350 char  Bat-Ball-Stump — a rock-paper-scissors-style cricket game in vanilla HTML/CSS/JS, no frameworks. Choose Bat, Ball, or Stump against a random computer pick (Bat beats Ball, Ball beats Stump, Stump beats Bat). Win/loss/tie scores persist via localStorage, with a Reset button to clear them. Great for practicing DOM basics.
